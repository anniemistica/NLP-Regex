# 🔎 NLP Regex Analyzer

A simple web-based **Natural Language Processing (NLP) Regex Analyzer** that uses **Regular Expressions (Regex)** to identify and extract useful patterns from text.

## 📌 About the Project

This project allows users to enter or paste text and analyze it using predefined Regex patterns.

It can detect:

* 📧 Email addresses
* 🌐 URLs
* 📱 Phone numbers
* #️⃣ Hashtags
* 👤 Mentions
* 📅 Dates
* 🖥️ IP addresses
* 🔢 Numbers
* 🔤 Words

It also displays basic text statistics such as **characters, words, sentences, and patterns found**.

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Regular Expressions (Regex)

## ⚙️ How It Works

Enter Text
    ↓
Click Analyze
    ↓
Apply Regex Patterns
    ↓
Extract Matching Data
    ↓
Display Results & Statistics

The application stores multiple Regex patterns and applies them to the entered text using JavaScript.

## ✨ Features

* Interactive text analysis
* Multiple Regex pattern detection
* Character and word counting

## 🧪 Example

### Input

Call +91-9876543210
#NLP @openai
Server: 192.168.1.1

URL         → https://www.example.com
Phone       → +91-9876543210
Hashtag     → #NLP
Mention     → @openai
IP Address  → 192.168.1.1

## 🚀 How to Run

1. Clone or download the repository.
2. Open the project in VS Code.
3. Open `index.html` in a web browser.

You can also use the **Live Server** extension in VS Code.
